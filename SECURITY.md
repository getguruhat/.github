# Security

If you find a security problem in a GuruHat app, please don't open a public issue. Email hello@guruhat.com with:

- the app and version
- what someone could do, and how
- steps to reproduce it, if you have them

You'll get a reply within 7 days. Fixes go out as a new GitHub release, and you'll be credited in the release notes unless you'd rather not be.

Only the latest release of each app gets security fixes.
