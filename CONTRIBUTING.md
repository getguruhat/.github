# Contributing to GuruHat

Thanks for helping. Every GuruHat app is free and open source, with no accounts, subscriptions, ads or tracking. Bug reports, ideas and pull requests are all welcome.

## Reporting a problem

Open an issue in the app's repo and pick the bug report form. Say which version you have and which OS version you're on. Never paste passwords, tokens, API keys or other private data.

## Your first contribution

1. Look for issues labelled `good first issue`, or fix something small you ran into yourself (a typo or an unclear sentence counts).
2. Comment on the issue so nobody else starts the same thing.
3. Fork the repo, make the change, and check that it builds.
4. Open a pull request and fill in the template.

You don't need to ask before sending a small fix. For a bigger change, open an issue first so we can agree on the approach before you spend time on it.

## Pull requests

- Keep a pull request to one change, and say how you tested it.
- Match the style of the code around it.
- GuruHat apps don't track people. Changes that add analytics, accounts, ads or calls to new servers won't be merged.
- By contributing, you agree that your work is released under that repo's licence.

## Updating a cask or Scoop manifest

Change the version, the download URL and the checksum together, and link the GitHub release the new version comes from.
