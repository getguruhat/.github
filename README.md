# getguruhat/.github

Default community files for every public repo under [getguruhat](https://github.com/getguruhat).

GitHub uses a file from here only when a repo doesn't have its own. A repo that has its own `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, PR template or `.github/ISSUE_TEMPLATE/` folder keeps using its own (ai-meter and ai-meter-windows do).

What's here:

- `CODE_OF_CONDUCT.md`
- `CONTRIBUTING.md`
- `SECURITY.md`
- `SUPPORT.md`
- `.github/ISSUE_TEMPLATE/` (bug report, idea, other, and contact links)
- `.github/pull_request_template.md`

A licence can't be shared this way. Each repo needs its own `LICENSE` file.
